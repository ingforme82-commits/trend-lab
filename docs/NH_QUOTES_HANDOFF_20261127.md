# Claude 인계 · NH 시세 연동 (2026-11-27)

## 확인 결과

- 국내: NH 국내주식 현재가 API에서 삼성전자(005930) KRX 요청이 성공했다. 실시간 스트림 검증은 남았다. 공식 SDK에 KRX, NXT, 통합 채널이 있다.
- 일본: 도요타(7203) 응답의 거래소는 TYO, 통화는 JPY였다. 실시간 구독에는 해외 종목마스터의 15자리 GIC가 필요하다.
- 대만: 코드 2330은 도쿄 종목으로 해석됐고 2330.TW는 거절됐다. TSMC·TAIEX의 NH 경로는 미확인이다. 기존 대만 시세 경로를 유지하고 거래소·통화가 확인된 별도 데이터원을 사용한다.
- 미국 시간외: TRL은 기존 quotes 브랜치의 1분 스냅샷에서 KORU·SOXL을 읽는다. 11월 27일 조회에서 두 응답은 trade_date가 11월 25일이고 quote_time의 시가 25였다. 시간 필드의 세션 규칙을 NH에 확인하기 전에는 실시간으로 판단하기 어렵다.

## 반영 사항

tools/nh_quotes.py는 조회일보다 2일 이상 지난 미국 거래일이나 읽을 수 없는 거래일의 시간외 시세를 stale로 분류한다. 후속 조회로 두 종목의 stale=true, live=false를 확인했다. 거래일만 확인하는 보수적 판정이며, 장중 실시간 여부와 휴장·시간외 세션 경계 검증은 남았다.

## 이어서 할 일

1. 국내와 일본은 종목별 WebSocket 체결을 수신해 원천 시각, 거래소, 통화, 실시간 수신 권한을 확인한다.
2. 대만은 TSMC와 TAIEX의 데이터원을 각각 확인하고 종가·지연·실시간을 원천 기준으로 표시한다.
3. 미국 시간외는 세션 코드, 24시 초과 시각, 휴장·조기 종료일을 대조한 후 최신성 판단을 정교화한다.
4. 공개 TRL 반영 전 데이터 제공 범위와 브라우저 표시를 확인한다. 기존 수집 명령은 python tools/nh_quotes.py이며 --publish 사용 시 공개 quotes 브랜치로 발행한다.
