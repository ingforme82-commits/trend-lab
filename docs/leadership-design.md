# Sector Momentum · Leadership Score 설계 (후속 단계, 미구현)

> 상태: **설계만 완료.** KB증권 API 사용 가능 여부·약관 확인 전이라 구현하지 않았다.
> 점수는 시장 데이터의 상대 순위일 뿐이며 매수·매도 권유가 아니다. 화면에도 이 문구를 함께 둔다.

## 1. 목적
국내 장중에 "어느 섹터·종목으로 거래대금과 수급이 몰리고 있는가"를 숫자로 보여 준다.
해석 문장은 자동 생성하지 않는다(운영자 '💡 해석' 노트와 분리).

## 2. 데이터 (출처 · 갱신 · 대체 경로)

| 항목 | 1순위(KB증권 API, 확인 필요) | 현재 대체 경로 | 갱신 |
|---|---|---|---|
| 현재가 · 누적 거래대금 | 현재가/체결 조회 | 네이버 polling(`tools/krx.py`, 이미 사용) | 1분 |
| 일봉 20~250일(5일선·고점·평균 거래대금) | 일봉 조회 | 야후 일봉(`sector_watch._quote`) | 하루 1회 + 장중 현재가로 보정 |
| 외국인·기관 순매수(장중 잠정 / 전일 확정) | 투자자별 매매동향 | 없음(누락 표시) | 장중 잠정 시각 기준 |
| 프로그램 순매수(차익·비차익) | 프로그램매매 동향 | 없음(누락 표시) | 장중 |
| 지수(코스피·코스닥) | 지수 시세 | 네이버 polling | 1분 |

- 키는 저장소 밖 `.env`(예: `tg_research/.env`)에서 읽고, 계산은 메인 PC의 `live_news.py`에서만 한다.
  브라우저에는 **집계 결과만** `news.json`으로 내보낸다(원천 시세 재배포 최소화, 키 노출 없음).
- KB증권 API 약관에서 **시세·수급 데이터의 외부 공개(재배포)**가 허용되는지 먼저 확인한다.
  허용되지 않으면 순위·점수(가공값)만 공개하고 원천 수치는 공개하지 않는다.
  사용자가 투자권유대행인이므로 준법 검토 후 공개한다.

## 3. 종목 지표 (대상: `data/sectors.json`의 국내 종목, 이후 코스피200 확장)

| 지표 | 계산 | 비고 |
|---|---|---|
| 거래대금 가속도 TVA | 당일 누적 거래대금 ÷ (20일 평균 거래대금 × 경과 비율 f(t)) | f(t): 최근 20일 분 단위 누적 거래대금 곡선의 평균(장 초반 쏠림 보정). 1.0 = 평소 속도 |
| 상대강도 RS | 당일 등락률 − 소속 시장 지수 등락률 | 20일 수익률 상대강도도 함께 저장 |
| 5일선 | (현재가 ÷ 5일 이동평균 − 1) × 100, 5일선 기울기 | 5일선 위/아래 여부 |
| 신고가 | 3개월·52주 고점 대비 %, 당일 신고가 여부 | 이미 `to3m`·`to52` 계산 중 |
| 외국인+기관 | 순매수 금액 ÷ 20일 평균 거래대금 | 장중 잠정치는 '잠정' 표시 |
| 프로그램 | 비차익 순매수 ÷ 20일 평균 거래대금 | |

## 4. Leadership Score (0~100)

1. 각 지표를 대상 종목 안에서 백분위 순위(0~100)로 바꾼다(단위가 달라도 비교 가능, 극단값 영향 감소).
2. 가중 평균

| 지표 | 가중치 |
|---|---|
| 거래대금 가속도 | 25 |
| 상대강도(당일) | 20 |
| 5일선 위치 | 15 |
| 신고가 근접 | 15 |
| 외국인+기관 순매수 | 15 |
| 프로그램 순매수 | 10 |

3. 누락된 지표는 빼고 남은 가중치로 다시 나눈다. 화면에는 **"수급 누락 — 4개 지표 기준"**처럼 표시한다.
4. 데이터 시각이 10분 넘게 지난 지표는 '지연'으로 표시하고 점수에서 뺀다.

## 5. Sector Momentum (섹터 단위)

- 구성 종목 Leadership Score 중앙값 40%
- 확산도(breadth): 상승 종목 비율, 5일선 위 종목 비율 평균 30%
- 거래대금 점유율 변화: 섹터 거래대금 ÷ 전체 감시 종목 거래대금, 20일 평균 대비 변화 30%
- 지속일수: `data/briefs.json`의 14:00 기록에서 상위 3위 안에 든 연속 일수(정보 표시만, 점수 미반영)

## 6. 화면 (사실·수치만)
- 섹터 칸 맨 위에 "📈 섹터 모멘텀 순위"(점수 + 구성 지표 막대 + 데이터 시각).
- 종목 이름을 누르면 지표별 값·순위·출처·시각.
- 14:00 브리핑에 섹터 상위 3개, 종목 상위 5개를 기록.

## 7. 검증 계획
- 단위 테스트: 백분위·가중 평균·누락 재정규화·지연 제외(`tests/test_leadership.py`).
- 과거 기록 비교: 2주 동안 14:00 기록과 실제 종가 흐름을 비교해 지표가 비어 있거나 한쪽으로 쏠리지 않는지 확인.
- 약관·준법 확인 전에는 화면에 공개하지 않고 `--dry`로만 계산한다.

## 8. 단계
1. (지금 가능) 네이버 거래대금 + 야후 일봉으로 TVA·RS·5일선·신고가 4개 지표 버전, 비공개 `--dry` 계산
2. KB증권 API 확인 후 수급·프로그램 추가
3. 약관·준법 확인 후 화면 공개
