# 점검 결과 (2026-10-27)

## 1. API 키·토큰 노출 — 이상 없음
- 공개 저장소의 현재 파일과 전체 커밋 이력(main·live)에서 `sk-ant-`·`ghp_`·`github_pat_`·AWS 키·개인 키 형식이 **0건**이다.
- `.env`, 세션, 토큰 파일은 저장소에 없다. `live_news.py`는 저장소 밖 `tg_research/.env`에서 키를 읽고 출력하지 않는다.
- 브라우저가 직접 부르는 API(하이퍼리퀴드, GitHub raw, abacus 카운터)는 키가 필요 없다.

## 4. 모바일 접근성
- 375px 폭 측정: 가로 넘침 요소 0개(옆으로 흐르는 상단 띠 제외).
- `lang="ko"`, viewport 설정, 움직임 줄이기(prefers-reduced-motion) 대응 있음.
- 이번에 고침: 그룹 스터디 사진의 빈 대체 텍스트(`alt=""`) → 회차 제목 + '현장 사진'.
- 속보 필터는 `<label>` 안의 `<select>`(높이 36px)라 화면 낭독기·터치에서 쓸 수 있음.
- 남은 과제: 시세 칸 작은 글씨(11.5px) 대비, 섹터·종목 버튼의 키보드 초점 표시 점검.

## 5. SEO
- 있음: title, description, Open Graph·트위터 카드, `lang`.
- 이번에 추가: canonical, `sitemap.xml`(블로그 글 포함, `publish.py`가 글 올릴 때 자동 갱신).
- 한계: 하위 경로(`github.io/trend-lab/`)라 `robots.txt`는 효과가 없다. 구글 서치 콘솔에 sitemap 제출은 운영자가 직접.
- 속보·시세는 JS로 그려 검색엔진에 잘 안 보인다(블로그 글 html은 정적이라 노출됨).
