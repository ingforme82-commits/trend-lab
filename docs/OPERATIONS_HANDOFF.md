## 공통 기준과 이번 변경
- WTI 관전 기준은 **85달러**. 화면 문구(news.js)와 즉시 하향 이탈 감지(tools/moves.py)를 함께 바꾼다.
- 실제 시세를 85달러로 고정하지 않는다. 과거 뉴스·브리핑의 당시 가격과 100달러 기록은 보존한다.
- 앱은 시세 30초, 속보·브리핑 요약 1분 주기로 갱신한다. 앱으로 돌아오거나 인터넷이 복구되면 즉시 자료를 다시 읽는다.
- 서비스 워커는 네트워크 우선. 화면 파일 변경 시 sw.js 버전을 올린다. 새 서비스 워커가 적용되면 기존 앱을 한 번 새로고침한다.
- CNBC 국채 10·30년물이 30분 넘게 오래되거나 없으면 야후를 조회하고 **원천 시각이 더 최신인 값만** 사용한다.
- 금리는 출처·마지막 시각·지연/휴장을 표시한다. 조회 시각을 원천 시각으로 바꾸지 않는다.
- 미국 채권 휴장일은 주식시장과 다르다. 2026년 일정은 market_extra.py UST_HOLIDAYS_2026, 원문은 SIFMA Holiday Schedule. 다음 해 일정 갱신 필요.
- KB 연결은 과거 오류 파일 유무로 정상 판정하지 않는다. healthcheck가 공개 현재가 한 건을 실제 조회한다. 키·토큰·원응답·계좌는 출력하지 않는다.
