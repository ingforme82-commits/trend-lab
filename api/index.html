Trend Research Lab

TRL Market Intelligence API

Free public beta for personal, non-commercial use. Use direct HTTPS GET requests without an account or API key.

Available datasets

  • API manifest (JSON) lists endpoints and indicator publication status.
  • TRL sector baskets JSON · CSV. Each row contains a TRL basket ID, English name, market and number of configured members. These are TRL research baskets. Membership counts describe the linked source revision.

Example

curl -fsS https://trlab.net/api/v1/sectors.json

Market indicators

Sector strength, trend score and capital-flow change are pending publication review. Their methodology and availability are listed in the manifest. The beta serves a versioned catalogue snapshot.
